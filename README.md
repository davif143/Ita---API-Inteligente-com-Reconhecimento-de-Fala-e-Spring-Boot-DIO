# Projeto API Inteligente com Spring AI

Este projeto foi desenvolvido como forma de estudo acompanhando de video aulas assistidas de um bootcamp elaborado pela DIO e Itaú,
como proposta de aprendizado de Java, Spring e IA.

## O que foi implementado?
Foi realizado uma API de orçamento que usa IA para processar comandos de voz relacionados a transações financeiras, de forma acompanhada das vídeo-aulas de resolução.

Posteriormente, tentei realizar uma melhoria na aplicação utilizando de Spring Security e JWT para praticar conceitos de segurança usando Spring.

## O que aprendi?
Durante as aulas e desevolvimento assistido do projeto, consegui aprender um pouco sobre Spring AI, como alguns conceitos nele funcionam e se relacionam com modelos de IA (LLM), como:
ChatClients, Tools, Prompts, ChatModels.

Além também de outros conceitos como, Segurança, APIs REST, pequenos detalhes sobre Clean Architecture, Drive-Domain Design (DDD).

## Quais ferramentas foram usadas?
- Java 21
- Spring Boot
- Spring Security
- Spring AI
- OpenAi Model
- Docker
- MySQL
